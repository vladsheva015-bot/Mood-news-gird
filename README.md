# Mood News Grid

Сервис, который показывает реальные новости из открытых источников и позволяет читать их в разных эмоциональных режимах.

## 📋 Функциональность

- Загрузка реальных новостей из RSS-лент (Lenta.ru, RIA.ru, TASS.ru, Vz.ru)
- Хранение новостей в SQLite
- Отображение новостей в виде карточек (грид)
- 5 режимов настроения: нейтральный, позитивный, грустный, ироничный, вдохновляющий
- По клику — оригинал и переписанный текст рядом
- Ссылка на оригинальный источник

## 🛠️ Технологии

- **Python 3.13**
- **FastAPI** — веб-фреймворк
- **Jinja2** — шаблонизатор
- **SQLite** — хранение данных
- **YandexGPT** — переписывание текста
- **RSS** — получение новостей

## 🚀 Запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/vladsheva015-bot/Mood-news-gird.git
cd Mood-news-gird

# 2. Создать виртуальное окружение
python -m venv .venv
.venv\Scripts\activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Создать .env файл (пример ниже)
cp .env.example .env

# 5. Запустить сервер
python run.py
